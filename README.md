# 七宗罪 | Seven Deadly Sins

基于 Phaser 3 的浏览器像素风动作 RPG。操控主角挑战以七宗罪为主题的七大 Boss，通过多武器切换、闪避翻滚和策略搭配征服每一场战斗。
事件房抉择除了持续生效的路线收益外，还会直接改写下一间战斗房的遭遇节奏：`下间缓冲 / 下间高压 / 下间淘金` 不只会调第三房的数值，还会同时重排敌群构成、开局阵型、接战时机与赏金载体，分别导向更深更宽且分拍接战的双低压开局、更贴近入口并立即成压的三敌夹击、或前后错层且后排目标会明确背更重赏金并挂 `赏金` 标记的双高赏金追击房；玩家刚踏进第三房时，还会先收到 `缓冲战 · 双拍缓冲` / `高压战 · 三向成压` / `淘金战 · 后排赏金` 这类极短开场预告，把 shrine route 直接钉进进房第一秒；当这个高赏金目标死亡时，还会立刻补一条 `赏金+X` 与更亮的金币爆点，而 `高压战 / 缓冲战` 继续维持更平均、更平稳的掉金反馈。第三房真正清场、Boss 门点亮时，还会再补一条 `缓冲战 · 稳住出清` / `高压战 · 顶住成压` / `淘金战 · 赏金到手` 这类极短收束语，把 route identity 从 shrine 选择、进房读图与关键击杀继续闭成完整的战斗段落。事件房抉择面板本身也会在高置信场景下把 `建议 1/2：净泉啜饮 · 可净化2层` 这类 shared recommendation 压进底部脚注，把当前状态真正收束成一眼可读的选择结论，但不会改动原有 1/2 顺序；若玩家真的按下这条高置信路线，已触发后的 HUD / 祭坛世界标签 / 结算浮字也会继续补 `治疗: 净泉啜饮 · 可净化2层` / `效果: 绝境修习 · 已处绝境线` 这类极短确认，让 recommendation reason 不只停在选前比较，而会延续到选后确认。`战技 / 镇压 / 战势 / 连携 / 反击` 这些行动型 blessing route 也会把 live combat state 接进同一套 recommendation helper，并在高置信场景下给出 `建议 1/2：连斩修习 · 普攻卡拍` / `游步修习 · 闪避卡拍` / `镇步修习 · 当前更宜控场` / `借势修习 · 特攻待借势` / `催锋修习 · 特攻待连段` / `回身修习 · 闪避待回身` / `追猎修习 · 可立即追猎` / `调息修习 · 当前更缺回体` 这类脚注，把动作路线也前移到选择前的比较结论。当这个已存储 reason 与 routed encounter 仍强相关时，第三房入口 / 清场短句还会继续补 `缓冲战 · 双拍缓冲 · 净化后稳场` / `高压战 · 三向成压 · 压线抢势` / `淘金战 · 后排赏金 · 血线够追赏` 这类更短遭遇回响；`命途圣坛` 的 `绝境修习 / 守心修习` 现在也会真正导向 `下间高压 / 下间缓冲`，把血线阈值 recommendation 接进下一房战术确认。同一套 routed encounter contract 现也开始吃进 build-facing 路线：`武备圣坛` 的 `压阵修习 / 离弦修习` 会分别把下一房压成 `下间高压 / 下间淘金`，`烙痕圣坛` 的 `余烬修习 / 血痕修习` 则会分别导向 `下间缓冲 / 下间高压`；若这些路线本身也是当下的高置信 recommendation，入口 / 清场 / 战中 source cue 还会继续补 `贴身压阵 / 远程追赏 / 灼烧稳场 / 挂血抢势`。其余行动型 blessing route 现在也会接进同一套 ladder：`战技圣坛` 的 `连斩修习 / 游步修习`、`镇压圣坛` 的 `镇步修习 / 破势修习`、`战势圣坛` 的 `回息修习 / 借势修习`、`连携圣坛` 的 `催锋修习 / 回身修习`、`反击圣坛` 的 `追猎修习 / 调息修习` 也会分别导向 `下间缓冲 / 下间高压 / 下间淘金`，并在没有高置信 recommendation receipt 时继续补 `连斩抢拍 / 游步整拍 / 镇步控场 / 破势追杀 / 回息稳场 / 借势重击 / 催锋连段 / 回身整拍 / 追猎追赏 / 调息回线` 这类 baseline anchor，把动作路线本身直接接到第三房第一段交手。当第三房真正开始兑现这条 recommendation 时，shared contract 还会只在首个稳场节点 / 首个高压接敌 / 首个赏金兑现点再补一次 `净化后稳场` / `压线抢势` / `血线够追赏` 这类战中 source cue，把“为什么推荐这条”接到实际交手瞬间。

## 快速开始

无需安装依赖，启动本地 HTTP 服务器即可运行：

```bash
# Python
python3 -m http.server 8000

# 或 Node.js
npx serve .
```

浏览器打开 `http://localhost:8000`。

## 操作指南

| 按键 | 操作 |
|------|------|
| WASD | 八方向移动 |
| I / J / K / L | 键盘双轴瞄准（松开时保留上次朝向） |
| U / 鼠标左键 | 普通攻击 |
| O / 鼠标右键 | 特殊攻击 |

| Q / E | 切换武器 |

| H | 操作指引 |
| Esc | 暂停菜单 |
| F | NPC / 事件房交互 |
